HOLLOWGOD - Prototype 0.2  (Godot 3.5)

SETUP
1. Unzip this folder somewhere easy, e.g. C:\Games\hollowgod  (replace the old 0.1 folder).
2. Open Godot 3.5. In the Project Manager click IMPORT.
3. Select the file  project.godot  in the hollowgod folder, click Open, then "Import & Edit".
4. Press F5 (Play). If asked for a main scene, choose scenes/Main.tscn.

CONTROLS
WASD move | Mouse aim | Left click or J attack (also swats enemy bolts) | Space or Shift dash
1 / 2 / 3 or click: pick a Gift | R restart | F11 fullscreen

WHAT'S NEW IN 0.2
- Brighter Sunken Hall: stone floor, ankh carvings, rune circle, drifting dust, vignette
- New enemy: Wisp (shoots bolts; swat them with your sword)
- Gifts: pick 1 of 3 random upgrades after each wave (8 different gifts)
- Boss: the Jackal Warden (charges, rings of bolts, calls minions at half health)
- First story choice: Restore / Bind / Release the Warden. The game remembers your choice
  next time you start (Oru comments on it). Saved in Godot's user folder.
- Damage numbers, dash recharge ring, boss health bar

If anything goes wrong, copy the red/yellow text from the bottom "Output" panel
and send it to me, or send a screenshot.
